# referencias-graficas/ — lenguaje gráfico real por marca

Igual que `logos-oficiales/`, esta carpeta es la única fuente de **lenguaje gráfico real** (fotografía, composición, iconografía, mood) por marca — imágenes de ejemplo que el dueño de la marca ya aprobó o quiere usar como referencia. Ningún manual o pieza debe inventar un estilo visual que no esté sustentado aquí o en el manual vigente.

Una carpeta por marca, usando el mismo `id` que `brand-tokens.json` (p. ej. `linex-trip/`). Suelta ahí capturas de pantalla, fotos, mockups o ejemplos de redes sociales que muestren el estilo que la marca quiere seguir.
